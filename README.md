# Homebrew Tap for Repotoire

## Install

```bash
brew install zach-hammad/tap/repotoire
```

Or:

```bash
brew tap zach-hammad/tap
brew install repotoire
```

## About

[Repotoire](https://github.com/Zach-hammad/repotoire) is a graph-powered code analysis tool with 81 detectors for security, architecture, and code quality.
